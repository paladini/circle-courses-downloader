Fast workflow, minimal friction.

Open your course, authenticate normally, and let the CLI manage lesson discovery and downloads.

1. Paste your course URL

Point the tool to a Circle course you can already access with your account.

2. Sign in through Chromium

The project uses a dedicated Playwright browser profile and keeps auth local on your machine.

3. Save and watch later

Videos are downloaded to your output folder with structured filenames and manifests.

Install in minutes.

Python 3.11+ is required. Install the package, install Chromium, then run one command.

python -m pip install circle-course-downloader
python -m playwright install chromium

circle-course-downloader download "https://your-community.example.com/c/course"

Built for practical offline learning.

Browser-only authentication

No password prompt in terminal, no token copy/paste flow, and no reading from your default browser data.

Manifest-driven downloads

Each run exports machine-readable JSON/CSV so your saved lessons remain organized and auditable.

Modern provider support

Detects Circle-hosted streams plus common embedded video providers used in course lessons.

Open source transparency

Public codebase, permissive MIT license, and a focused scope designed around respectful usage.

Personal/fair-use boundary.

Use responsibly

This tool is intended only for personal/offline use of content you are authorized to access. It does not bypass DRM, paywalls, 2FA, captchas, or Circle access controls, and it should be used in line with service terms.
