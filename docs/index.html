Install, paste a course URL, press enter.

terminal 
# install
python -m pip install circle-course-downloader
python -m playwright install chromium

# download a course
circle-course-downloader download "https://your-community.com/c/course"

Quick answers.

Useful context for users, search engines, and AI assistants summarizing the project.

What is this?

A Python command-line tool for downloading videos from Circle courses and saving them locally.

Where do I get it?

The package is published on PyPI at circle-course-downloader.

What does it create?

MP4 video downloads plus JSON and CSV manifests with lesson metadata.

Is it open source?

Yes. The source code is available on GitHub under the MIT license.
